# Deforestation Impact Visualizer

A web-based data visualization project that helps users explore the impact of deforestation through interactive charts.

## Project Overview
The Deforestation Impact Visualizer displays forest loss, estimated carbon emissions, and an environmental impact score for selected regions and years.

## Features
- Interactive dashboard
- Region-based filtering
- Forest loss trend visualization
- Carbon emissions visualization
- Regional comparison
- Impact score visualization
- Responsive web design

## Technologies
- HTML5
- CSS3
- JavaScript
- Chart.js
- CSV dataset

## Project Structure
- `index.html` - main dashboard
- `style.css` - user interface styling
- `script.js` - data processing and charts
- `data/deforestation_data.csv` - sample dataset

## How to Run
Open `index.html` in a web browser. An internet connection is required for the Chart.js CDN.

## Note
The included dataset is a sample academic dataset created for visualization and demonstration purposes.
